## **7. Mission Phases**
### **Phase 1:**
- CASE I from CVN-73 (WF)
- FPAS CLAIM angles 30

### **Phase 2:**
- FORM UP en Route
- PUSH PRI11 Focus31
- CLIMB angles 35

### **Phase 3:**
- Sign in with Focus on Pri 11
- cross reference target assignments
- FENCE

### **Phase 4:**
- Proceed to RELEASE point via IP (15nm)
- JSOW (PP) on assigned targets (SA-11 C&C, SR & launchers)
- right hand orbit
- HARM release PP (115 / SA-11, 119 / SA-15)

### **Phase 5:**
- BDA if cloud layers allow
- stay North/West of W5 Barrier

### **Phase 6:**
- Egress via W1 Fence
- AAR @ Shell (optional)
- PUSH PRI16 CVN-5
